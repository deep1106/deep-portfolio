# Deep Bhavsar — AI systems, built in the field

A standalone, responsive portfolio focused on practical AI, automation, and forward deployed engineering.

## Preview

Open `index.html` directly, or serve this directory from a local static server. The page uses no framework or build step.

## Update before publishing

- Replace the canonical URL and Open Graph URL in `index.html` and sitemap/robots entries if the site is published at a different domain.
- Publish the folder contents at the site root so the canonical URL, sitemap, robots file, and social image resolve correctly.
- Keep Shayona workflow exports and connected account identifiers private. The case study links to the public storefront instead.

## Files

- `index.html` — content, structured data, and page metadata
- `styles.css` — responsive field-notes visual system and project illustrations
- `script.js` — project filters and mobile navigation
- `favicon.svg`, `og-image.svg` — brand assets
- `robots.txt`, `sitemap.xml` — crawler discovery
- `llms.txt` — concise machine-readable site guide
