## 2026-09-26 - [Security Enhancement: Contact Form Validation]\n**Vulnerability:** Lack of input validation, type checking, and bounds checking on the contact form API endpoint (`functions/api/contact.ts`). This left the endpoint vulnerable to large payload DoS attacks, unexpected types (which could cause runtime errors or bypass logic), and basic XSS if logs were viewed unsafely.\n**Learning:** Even simple logging endpoints need full input validation and length bounds before processing or logging data, particularly on public-facing APIs like contact forms.\n**Prevention:** Always validate input types, enforce length limits appropriate for the expected data, and perform basic sanitization before logging or using user input.
