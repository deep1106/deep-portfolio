## 📁 Repository Structure

The current portfolio redesign lives in [`portfolio by codex/`](portfolio%20by%20codex/). Cloudflare Pages deploys that folder from `main` after the redesign is merged.

```
├── public/
│   ├── index.html          # Main portfolio page
│   ├── css/
│   │   └── style.css       # Custom dark theme styles
│   └── js/
│       └── main.js         # Interactive features
├── functions/
│   └── api/
│       └── contact.ts      # Contact form backend API
├── .github/
│   └── workflows/
│       └── deploy.yml      # Cloudflare Pages deployment
├── package.json
└── wrangler.toml
```

## 📦 Local Development

1. Clone the repository
2. Install dependencies: `npm install`
3. Run locally: `npx wrangler pages dev public`

## 🚀 Deployment

The site is automatically deployed to Cloudflare Pages on every push to the `main` branch.
